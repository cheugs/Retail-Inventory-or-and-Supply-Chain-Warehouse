06
Architecture

Le chemin d'une donnée

Airflow lance chaque jour le chargement, la transformation dbt, les tests et le rapprochement. Les couches sont séparées : brut, nettoyé, modèle en étoile, quarantaine et audit.

Faits

fct_sales (ligne de ticket, incrémental), fct_inventory_daily (photo quotidienne, incrémental), fct_purchase_order_lines (snapshot accumulatif).

Dimensions

dim_product (SCD type 2 : prix, coût, fournisseur), dim_store et dim_supplier (SCD type 1), dim_date.

Données en retard

Fenêtre de retraitement de 3 jours, membre "produit inconnu" corrigé au run suivant, historique SCD2 reconstruit à chaque run.
